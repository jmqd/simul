#+title: Changelog

* DONE Address initial-queue messages to their owner
=Simulation::try_new= sets each initial-queue message's =destination= to the
agent that owns the queue, so consumed initial messages no longer look
undeliverable. =destination= is =None= only when a send matched no agent.

* DONE Share message payloads as Arc<[u8]> (breaking)
=Message::custom_payload= is a public =Option<Arc<[u8]>>=, and =send=, =send_to=,
and =Message::new_with_payload= take that type. A new payload allocates once,
forwarding =message.custom_payload.clone()= only increments a reference count,
and =Arc::make_mut= edits copy-on-write. The engine never set or read the
=Message::interrupt= field, so it, =Interrupt=, and =MessageBody= are removed;
halt with =ctx.send_halt_interrupt=. =AgentId= stores =index + 1= so =Message=
stays 48 bytes, and =AgentId::new(u32::MAX)= panics. The nine-ball and
software-team examples build payloads from stack arrays. Payload forwarding in a
16-agent ring retires 57% fewer instructions; the software-team example 17%.

* DONE Reuse bounded parallel workers across batches
=ParallelExecutor= retains a dedicated Rayon pool with construction-time capacity.
Each run still validates and allocates before initializing fresh caller-thread
workspaces, then returns canonical replayable records. Empty and failed batches
leave the executor reusable; one-shot =run_parallel= remains available. Ported
from perf-hotpaths ec14848; 2,000 batches of 16 trials take 28 ms instead of
120 ms with one-shot pools.

* DONE Skip inactive agents during sparse simulation phases
Simulations with more than 64 agents and neither per-tick metric use a ready
bitmap and wake heap while retaining handle-ordered callbacks, end-of-tick
delivery, and per-tick halt checks. Scheduling state is rebuilt on resume, and
wake transitions stay ordered even if a callback panics. Small, busy, and
metrics-enabled simulations scan densely. Ported from perf-hotpaths d9ed3ad; a
520-agent sparse population retires 76% fewer instructions, and 10,000 ticks
with 10,000 idle agents run in 19 ms instead of 552 ms.

* DONE Cut per-message, per-trial, and search overhead
Simulations with at most eight agents route messages by scanning names; larger
ones hash names with rustc-hash, and Clippy bans the std hash maps. Built-in
producers cache their target identity per simulation layout, so an agent cloned
into another simulation resolves again. Still-sleeping agents skip the callback
path, and small simulations reserve 16 messages per history and queue.
SeededRandomSearch keeps untold proposals in a token window instead of a BTreeMap,
derives told tokens instead of storing them, and validates small tell batches
without allocating. Seed derivation hashes the concatenated V1 fields in one BLAKE3
call; frozen seed vectors, including new long-tag vectors, are unchanged. CEM
sampling skips fmod for in-domain coordinates with bit-identical results.
With the AgentId change, retired instructions on the deterministic workloads fall
32-81% for simulations, 56% for a 1,000-candidate simulation search, 4-19% for
trial streams and search bookkeeping, and 5% for CEM, with identical outputs.

* DONE Identify message agents by AgentId
Agents have dense AgentId identities in construction order. Messages carry source
and destination identities instead of names, so a send without a payload allocates
nothing. Message::new(time) and Message::new_with_payload(time, payload) no longer
take names; source is None for initial queue entries, and destination is None when
a target matches no agent, which is recorded without delivery as before.
AgentContext::id replaces handle; send_to sends by identity, agent_id resolves a
name once, and Simulation::agent and agent_id translate identities.
SimulationError::TooManyAgents rejects more than u32::MAX agents.

* DONE Refresh dependencies and tooling (October 2026)
Pin Rust 1.99.1 and update rand to 0.10.3, rayon to 1.12.0, compatible Cargo
lockfile dependencies, and the Nix flake inputs. Update Dylint to 6.2.0 with
nightly-2026-08-20. Keep the library MSRV at 1.85; tests and benchmarks require 1.86.
Clippy 1.99's assert_is_empty lint reworded four test assertions. The example
replay comparison is unchanged by the refresh. Verify native tests, Clippy,
formatting, audit, docs, licenses, unused dependencies, Rust 1.85 library
compilation, and the Nix package and dev shell on Apple Silicon. All four Nix
platforms evaluate; Intel macOS and Linux builds were not exercised.
Dylint completes with non-fatal assertion-order and crate-wide-allow warnings.

* DONE Add a catalogue of example candidates
Describe example programs worth writing, each chosen for a real-world dynamic
that averaged models miss. Include a worked brief for a billiards cafe that maps
onto the agent engine and the experiment module, and link it from the README.

* DONE Avoid temporary allocations for singleton search results
Skip within-batch duplicate sets and the canonical sorting buffer when a tell
contains one result. Preserve identity validation and atomic rejection of invalid
results, while keeping canonical ordering for batches.

* DONE Stabilize Wilson confidence intervals at numeric extremes
Rationalize the lower confidence bound to avoid cancellation, and rescale large
z-scores before squaring. Preserve representable tiny bounds instead of rounding
them away through intermediate overflow or underflow.

* DONE Preserve tiny centers in complete circular refits
At learning rate one, use the elite center directly instead of subtracting and
re-adding the previous center. Small representable circular coordinates no longer
round to zero during a complete refit.

* DONE Preserve tiny optimizer standard deviations
Avoid variance underflow and subnormal precision loss during smoothing and
complete refits. Use deviation arithmetic when the weighted variance cannot
retain normal precision, rather than collapsing a representable spread to its
minimum. Normal-scale seeded optimizer replay remains bit-identical.

* DONE Update reviewed random-number dependencies
Upgrade rand to 0.10.3 and zerocopy/zerocopy-derive to 0.8.62 for upstream numeric
and pointer-metadata fixes. Keep the library MSRV at 1.85; frozen seed vectors,
seeded optimizer proposals, and simulation replay remain unchanged.

* DONE Update the development toolchain to Rust 1.99.0
Refresh rust-overlay to provide the pinned compiler on all four Nix platforms.
Keep the library MSRV at 1.85 and adapt empty-result assertions to the new Clippy
diagnostics. Seeded optimizer and simulation replay matches Rust 1.98.1 exactly.

* DONE Reuse repeated payload-free message contents
Consecutive sends with unchanged source and destination can share retained
contents instead of reallocating message bodies and names. Timestamps and
copy-on-write edits remain independent; payload and history changes are respected.

* DONE Reduce per-turn allocation in the nine-ball example
Build each player's weighted distribution once per match, borrow message payloads
when decoding the ball, and borrow the next player's name when sending a turn.

* DONE Skip projection for already-normalized optimizer coordinates
Avoid floating-point remainder operations for coordinates already inside their
linear or circular domain. Seeded proposal and update replay remains bit-identical.

* DONE Fail license checks when collection or filtering fails
Preserve errors from cargo-license instead of reporting success for missing or
failed tooling. A license-filter error also fails the check.

* DONE Restore the nine-ball simulation example
Record the winning agent explicitly, give both normal-rules players unique names,
and queue the opening turn only for the chosen starter. Winning turns halt without
scheduling another turn. Label the APA and normal-rules result tables correctly.

* DONE Preserve short waits at large simulation timestamps
Subtract integer timestamps before converting waiting durations to floating point.
One-tick waits remain accurate above 2^53 and near the u64 time limit.

* DONE Consolidate typed experiments and eager worker setup
Use one trial/replay protocol with bounded canonical serial and parallel runners.
Worker initialization is fallible and eager; explicit storage is allocated before
callbacks, and callback unwinding yields run-level errors without retries.
Remove the duplicate replicated runner, TrialKey alias, and simulation-coupled
search wrappers. Retain generic annealing and cross-entropy optimization.

* DONE Sample finite bounds without interval-width overflow
Opposite-sign extreme endpoints use a finite convex combination.
Representable-width intervals retain their existing deterministic samples.

* DONE Reject unrepresentable scalar statistics
Scalar reduction reports arithmetic overflow without changing accepted state.
Aggregation preserves that failure instead of returning non-finite statistics.

* DONE Share retained message contents without deep cloning
Message histories and delivery share strings and payloads with copy-on-write
mutation; completion timestamps remain independent. Construct messages with
=Message::new= or =Message::new_with_payload= instead of struct literals.

* DONE Use one replication result allocation
Workers fill disjoint output ranges directly; partial results are dropped on
failure. Worker-count tests cover single-CPU and unavailable-parallelism hosts.
The obsolete =WorkerChunkRecords= allocation-error variant was removed.

* DONE Preserve optimizer numerical boundaries
Circular proposals stay in =[0, 1)=, finite sampling and deviation smoothing
avoid overflow, and annealing preserves acceptance across extreme finite scores.

* DONE Reject simulation time overflow consistently
Tick advancement is checked before callbacks; sleep requests reject overflowing
wake times before changing state. Both checks also apply in release builds.

* DONE Protect agent routing identity
AgentContext exposes its handle through =handle()= instead of a writable field.
=find_by_name_mut= returns mutable behavior and state, not a replaceable agent.
Command dispatch uses bounds-checked indexing.
