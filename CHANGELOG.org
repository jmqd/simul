#+title: Changelog

* DONE Seed simulations from experiment trials
=SimulationBuilder::trial(&TrialContext)= seeds a simulation from the trial's
common-random =TrialNoise= stream tagged =simul::Simulation=. Candidates
evaluated in one common-random group share their agents' draws replication by
replication, and each replication draws afresh, so paired comparisons under
=run_serial= or =run_parallel= need no hand-built seed. No example or test
previously connected a trial to a simulation seed; =simple_experiment= now
does, with unchanged output.

* DONE Send messages that arrive after a delay
=AgentContext::send_after(delay, id, payload)= makes a message visible to
its target from tick =time() + delay=; =send_after(1, ..)= is =send_to=. The
message counts as sent at once and carries =queued_time= =time() + delay - 1=,
so it queues, records, and reports its wait as if sent then. Messages arriving
in one tick come in send order, so delayed ones precede that tick's ordinary
sends. Quiet-tick skipping stops at the next arrival, and messages still in
flight when a run halts stay in =Simulation::in_flight= for the next run. A
responder that replies 50 ticks after each of 9,968 requests over 10 million
ticks took 143 ms polling every tick and takes 2 ms with =send_after=, with the
same replies. A zero delay panics. The engine laws now send a third of their
chaos messages with delays.

* DONE Read finished agents back as their own type
=SimulationAgent::downcast_ref::<A>()= returns an agent's behavior as an =A=,
or =None= for any other type, so results can stay in agent fields instead of
in =Rc<Cell<_>>= or lock-guarded state shared with the agent. Agents get a
sealed supertrait that gives every ='static= type an =Any= view; it has no =Any=
supertrait itself, so the message type need not be ='static=. The nine-ball
example reads each match's winner from the players instead of an
=Rc<Cell<Option<usize>>>=.

* DONE Type messages by the simulation's message type (breaking)
=Simulation<M>=, =Agent<M>=, =AgentContext<'_, M>=, and =Message<M>= carry one
message type chosen by the model, usually an enum, with =()= as the default.
=ctx.send= and =send_to= take an =M=, =Message::new(time, payload)= replaces
=new= and =new_with_payload=, and =Message::custom_payload= becomes =payload=.
Handlers match on =message.payload=, so the software-team example drops its
byte codec (149 lines) and every decode-failure arm; nine-ball passes the ball
as a =u8=. Agents that ignore payloads implement =Agent<M>= for every =M=: the
built-in consumers do, and the built-in producers send =M::default()=. Name
the type where nothing else fixes it, as =Simulation::<()>::builder(halt)= or
=periodic_consumer::<Msg>(name, 1)=. Built-ins take each name as
=impl Into<String>=, so a name and a target may be different string types. A
payload moves into the receiver's queue; only =message_history(true)= needs
=M: Clone=. Byte payloads remain available as =M = Option<Arc<[u8]>>=, which the
ETL example and the engine laws use. =Message<()>= is 32 bytes.

* DONE Add an ETL placement simulation example
=examples/etl_placement= asks where a Supabase ETL replicator should run when
its source Postgres is in us-west-2 and its destination in us-east-1. Three
agents exchange units over flow-level TCP with per-connection RTT draws,
CUBIC, idle restart, receive-window credit, retransmission backoff across
partitions, and Postgres/TLS handshakes; the replicator follows
supabase/etl's batching, blocking store checkpoints, keepalive feedback,
parallel copy, catch-up, and retries. Both placements run under common
random numbers through a CDC rate × =max_fill_ms= sweep, an initial copy,
and six faults. Every parameter names its source or is marked ASSUMPTION.
Run =cargo run --release --example etl_placement -- --help= for options.

* DONE Record message histories only on request (breaking)
=AgentState::consumed= and =produced= are gone. Agents count consumed and
produced messages and sum their waits as they go
(=SimulationAgent::consumed_count=, =produced_count=), so
=calc_avg_wait_statistics= and the count statistics, which now return =u64=,
need no history. =SimulationBuilder::message_history(true)= keeps every
message, read with =SimulationAgent::consumed= and =produced= or
=Simulation::consumed_for_agent= and =produced_for_agent=; these panic when
history is off instead of returning an empty slice, which would make a halt
condition on it never fire. Recorded histories are read-only. Without
history, a delivery moves the message instead of cloning it: a 10-million-tick
producer/consumer pair runs in about 300 ms instead of 770 ms and peaks at
2 MiB instead of 918 MiB. With history on, time and memory are unchanged.

* DONE Key agent streams by name and seek instead of hashing (breaking)
Each agent's =AgentContext::rng()= streams come from one =ChaCha12= key,
hashed once at build time from the simulation seed and the agent's name.
Each tick is a stream of that key, and each call within a tick reads its own
window of it. Adding, removing, or reordering other agents no longer changes
an agent's draws, so common random numbers survive candidates that add an
agent, such as a seventh table. A call costs about 75 ns instead of 260 ns.
=SeedDeriver::agent_seed= is replaced by =SeedDeriver::agent_streams= and
=AgentStreams::rng=. Frozen V1 experiment streams are unchanged.

* DONE Sample rand distributions from seeded streams
=TrialRng= implements =rand::TryRng= with =Infallible= errors, and therefore
=rand::Rng=, so =rand= and =rand_distr= samplers can draw from
=AgentContext::rng()=, trial streams, and proposal streams. The inherent
methods are unchanged. The nine-ball example drew from the unseeded thread
RNG for lack of this; it now seeds each match, so its output is
reproducible, and every luck chance replays the same match seeds.

* DONE Skip quiet ticks
With =Halt::AtTime= or =Halt::Never= and the asleep-cycle metric off, a tick
in which no callback ran jumps time to the next tick where an agent can act,
capped at the halt time. Such ticks issue no commands, so results match
running every tick; =Halt::when= predicates still see every tick. A producer
acting every 1,000 ticks beside 10,000 idle agents runs 10 million ticks in
6.9 ms instead of 603 ms.

* DONE Record queue depths as changes (breaking)
=Simulation::queue_depth_metrics= returns =&[QueueDepthChange]= (=time=,
=depth=), recorded only when a pop, a delivery, or an in-progress requeue
changes the depth an agent's visit observes; expanding the changes step-wise
reproduces the old per-tick series. The metric no longer forces dense
scheduling. 10,000 idle agents over 10,000 ticks with the metric on run in
6.2 ms and 7.6 MB instead of 824 ms and 1.95 GB.

* DONE Measure circular means from a reference elite
=circular_mean= sums angles relative to the best elite, so one elite or
identical elites refit to their exact coordinate, and an exact half-turn tie
always moves in the negative direction instead of depending on how the
platform's =sin=, =cos=, and =atan2= round. Circular CEM results change in
their last bits.

* DONE Make CEM updates independent of sample order
Elites are ordered best first with ties broken by point, and the selection
path sorts them before fitting, so =tell= gives bit-identical updates for any
input order or NaN placement. Before, one NaN in front of tied samples could
change the elite set, and above 12 samples the fitted mean could differ in the
last bit. =best()= on a tie now keeps the lowest point instead of the last one
scanned.

* DONE Read elite fractions as decimals
=elite_count= snaps a product within a few ulps of an integer to that integer
before rounding up, so 0.07 of 100 samples selects 7 elites instead of 8.
Populations whose products used to round up by one ulp now select one fewer
elite, which changes their CEM updates.

* DONE Drop the log dependency; report halt reasons (breaking)
The engine no longer emits =log= records, so =log= is gone from the dependency
tree and the per-tick =debug!= calls are gone from the hot loop. The reason
passed to =send_halt_interrupt= used to be logged at =info= and is now
returned by =Simulation::halt_reason()=.

* DONE Seal Bernoulli and scalar summaries (breaking)
=BernoulliSummary= and =ScalarSummary= fields are private; read them with
same-named getters such as =rate()= and =mean()=. Only =BernoulliReducer= and
=ScalarReducer= build them, so summaries are always finite and selection
policies never see a NaN rate. =CandidateSummary= stays a public data carrier
for caller-defined statistics.

* DONE Build simulations with Simulation::builder (breaking)
=SimulationParameters=, =Simulation::new=, and =Simulation::try_new= are
replaced by =Simulation::builder(halt)=, which takes the required =Halt= up
front and offers =agent=, =agents=, =starting_time=, =seed=,
=queue_depth_metrics=, and =asleep_cycles_metric=. =build()= returns
=Result<Simulation, SimulationError>=. The old =Default= halted before the
first tick, so a forgotten halt check silently ran nothing.

* DONE Declare halt conditions with Halt (breaking)
=SimulationParameters::halt_check: fn(&Simulation) -> bool= is replaced by
=halt: Halt=: =Halt::AtTime(t)= stops once time reaches =t=, =Halt::Never= runs
until a halt interrupt, and =Halt::when(predicate)= accepts closures that
capture state, which function pointers could not.

* DONE Replace Poisson agents with seeded geometric agents (breaking)
=poisson_distributed_producer= and =poisson_distributed_consumer= took a
=rand_distr::Poisson<f64>=, drew from the unseeded thread RNG, and treated a
zero-tick sample as one tick, so their mean period was λ + e^{-λ} and their
gaps were not memoryless. =geometric_producer(name, mean, target)= and
=geometric_consumer(name, mean)= draw memoryless geometric gaps of at least one
tick from =AgentContext::rng()=, with exactly the requested mean (at least 1),
and the public API no longer exposes =rand_distr= types.

* DONE Seed simulations and give agents per-tick random streams (breaking)
=Simulation::builder(..).seed(..)= roots =AgentContext::rng()=, which returns
a =TrialRng= derived from the seed, the agent's =AgentId=, the tick, and the
call's index within the tick, under the new =simul/v1/agent= namespace
(=SeedDeriver::agent_seed=). Draws do not depend on
other agents, sparse or dense scheduling, clones, or how a run is split into
segments. Frozen V1 experiment streams are unchanged.
Superseded by "Key agent streams by name and seek instead of hashing":
streams are keyed by agent name, not =AgentId=, and are not hashed per call.

* DONE Deliver messages to Proactive agents (breaking)
Each tick, an awake agent with a queued message handles the oldest one in
=on_message=; a Proactive agent then also gets =on_tick=. Messages sent to
Proactive agents used to pile up unread. =Agent::on_message= now has a default
empty body, so agents that never receive messages need not implement it.

* DONE Fail simulations whose callbacks panic (breaking)
A panic from an agent callback or the halt check leaves the simulation
=SimulationMode::Failed=, and =run= refuses to resume it instead of replaying
part of the interrupted tick. =Simulation::mode()= reports the mode, and
=SimulationMode= is now =Copy=.

* DONE Make AgentContext fields read-only (breaking)
=name=, =time=, =state=, and =message_processing_status= are private. Read
them with =ctx.name()=, =ctx.time()=, and =ctx.state()=; set the status with
=set_processing_status=. Callbacks could previously overwrite =ctx.name=,
which rerouted sends in simulations of eight or fewer agents.

* DONE Expose engine types only through their modules (breaking)
The crate root no longer glob re-exports =agent::*= and =message::*=; import
them from =simul::agent= and =simul::message=. =AgentCommand= and
=AgentCommandType= were public but unusable outside the engine and are now
crate-private.

* DONE Address initial-queue messages to their owner
=Simulation::try_new= sets each initial-queue message's =destination= to the
agent that owns the queue, so consumed initial messages no longer look
undeliverable. Messages pushed into a queue between runs keep the
=destination= they were built with.

* DONE Reflect linear cross-entropy coordinates exactly
Linear coordinates below zero reflect as =|value| % 2= instead of through
=rem_euclid(2.0)=, which rounded =2 + value=. A draw of -0.3 now reflects to
exactly 0.3, and tiny negative draws such as -1e-200 no longer collapse to 0.
Some reflected samples change in their last bits.

* DONE Keep runners and search consistent when callbacks panic
A panic payload whose destructor panics becomes the documented
=WorkloadPanic= / =WorkerWorkloadPanic= error instead of unwinding out of
=run_serial= or =run_parallel=. Discarding partial parallel output keeps
dropping records after one record's destructor panics. =SeededRandomSearch=
issues =ask= tokens only after every generator and candidate clone returns,
and =tell= runs every policy comparison and summary clone before changing
state, so a caught generator, policy, or =Clone= panic leaves the search
unchanged and retryable.

* DONE Rank NaN lowest in Bernoulli selection policies
=MaximizeBernoulliRate= and =MaximizeWilsonLowerBound= rank a NaN rate or bound
below every number instead of treating it as equal to all of them, so
=select_best= no longer depends on input order for such summaries.

* DONE Share message payloads as Arc<[u8]> (breaking)
=Message::custom_payload= is a public =Option<Arc<[u8]>>=, and =send=, =send_to=,
and =Message::new_with_payload= take that type. A new payload allocates once,
forwarding =message.custom_payload.clone()= only increments a reference count,
and =Arc::make_mut= edits copy-on-write. The engine never set or read the
=Message::interrupt= field, so it, =Interrupt=, and =MessageBody= are removed;
halt with =ctx.send_halt_interrupt=. =AgentId= stores =index + 1= so =Message=
stays 48 bytes, and =AgentId::new(u32::MAX)= panics. The nine-ball and
software-team examples build payloads from stack arrays. Payload forwarding in a
16-agent ring retires 57% fewer instructions; the software-team example 17%.
Superseded by "Type messages by the simulation's message type": payloads are
the model's own type, and =Option<Arc<[u8]>>= is one choice of it.

* DONE Reuse bounded parallel workers across batches
=ParallelExecutor= retains a dedicated Rayon pool with construction-time capacity.
Each run still validates and allocates before initializing fresh caller-thread
workspaces, then returns canonical replayable records. Empty and failed batches
leave the executor reusable; one-shot =run_parallel= remains available. Ported
from perf-hotpaths ec14848; 2,000 batches of 16 trials take 28 ms instead of
120 ms with one-shot pools.

* DONE Skip inactive agents during sparse simulation phases
Simulations with more than 64 agents and neither per-tick metric use a ready
bitmap and wake heap while retaining handle-ordered callbacks, end-of-tick
delivery, and per-tick halt checks. Scheduling state is rebuilt on resume, and
wake transitions stay ordered even if a callback panics. Small, busy, and
metrics-enabled simulations scan densely. Ported from perf-hotpaths d9ed3ad; a
520-agent sparse population retires 76% fewer instructions, and 10,000 ticks
with 10,000 idle agents run in 19 ms instead of 552 ms.

* DONE Cut per-message, per-trial, and search overhead
Simulations with at most eight agents route messages by scanning names; larger
ones hash names with rustc-hash, and Clippy bans the std hash maps. Built-in
producers cache their target identity per simulation layout, so an agent cloned
into another simulation resolves again. Still-sleeping agents skip the callback
path, and small simulations reserve 16 messages per history and queue.
SeededRandomSearch keeps untold proposals in a token window instead of a BTreeMap,
derives told tokens instead of storing them, and validates small tell batches
without allocating. Seed derivation hashes the concatenated V1 fields in one BLAKE3
call; frozen seed vectors, including new long-tag vectors, are unchanged. CEM
sampling skips fmod for in-domain coordinates with bit-identical results.
With the AgentId change, retired instructions on the deterministic workloads fall
32-81% for simulations, 56% for a 1,000-candidate simulation search, 4-19% for
trial streams and search bookkeeping, and 5% for CEM, with identical outputs.

* DONE Identify message agents by AgentId
Agents have dense AgentId identities in construction order. Messages carry source
and destination identities instead of names, so a send without a payload allocates
nothing. Message::new(time) and Message::new_with_payload(time, payload) no longer
take names; source is None for initial queue entries, and destination is None when
a target matches no agent, which is recorded without delivery as before.
AgentContext::id replaces handle; send_to sends by identity, agent_id resolves a
name once, and Simulation::agent and agent_id translate identities.
SimulationError::TooManyAgents rejects more than u32::MAX agents.

* DONE Avoid temporary allocations for singleton search results
Skip within-batch duplicate sets and the canonical sorting buffer when a tell
contains one result. Preserve identity validation and atomic rejection of invalid
results, while keeping canonical ordering for batches.

* DONE Stabilize Wilson confidence intervals at numeric extremes
Rationalize the lower confidence bound to avoid cancellation, and rescale large
z-scores before squaring. Preserve representable tiny bounds instead of rounding
them away through intermediate overflow or underflow.

* DONE Preserve tiny centers in complete circular refits
At learning rate one, use the elite center directly instead of subtracting and
re-adding the previous center. Small representable circular coordinates no longer
round to zero during a complete refit.

* DONE Preserve tiny optimizer standard deviations
Avoid variance underflow and subnormal precision loss during smoothing and
complete refits. Use deviation arithmetic when the weighted variance cannot
retain normal precision, rather than collapsing a representable spread to its
minimum. Normal-scale seeded optimizer replay remains bit-identical.

* DONE Reuse repeated payload-free message contents
Consecutive sends with unchanged source and destination can share retained
contents instead of reallocating message bodies and names. Timestamps and

Superseded by "Identify message agents by AgentId": messages no longer hold

* DONE Reduce per-turn allocation in the nine-ball example

* DONE Consolidate typed experiments and eager worker setup
Use one trial/replay protocol with bounded canonical serial and parallel runners.
Worker initialization is fallible and eager; explicit storage is allocated before
callbacks, and callback unwinding yields run-level errors without retries.
Remove the duplicate replicated runner, TrialKey alias, and simulation-coupled
search wrappers. Retain generic annealing and cross-entropy optimization.

* DONE Sample finite bounds without interval-width overflow
Opposite-sign extreme endpoints use a finite convex combination.
Representable-width intervals retain their existing deterministic samples.

* DONE Reject unrepresentable scalar statistics
Scalar reduction reports arithmetic overflow without changing accepted state.
Aggregation preserves that failure instead of returning non-finite statistics.

* DONE Share retained message contents without deep cloning
Message histories and delivery share strings and payloads with copy-on-write
mutation; completion timestamps remain independent. Construct messages with
=Message::new= or =Message::new_with_payload= instead of struct literals.
Superseded by "Identify message agents by AgentId" and "Share message payloads
as Arc<[u8]>": messages hold identities, not strings, and only payloads are
shared.

* DONE Use one replication result allocation
Workers fill disjoint output ranges directly; partial results are dropped on
failure. Worker-count tests cover single-CPU and unavailable-parallelism hosts.
The obsolete =WorkerChunkRecords= allocation-error variant was removed.

* DONE Preserve optimizer numerical boundaries
Circular proposals stay in =[0, 1)=, finite sampling and deviation smoothing
avoid overflow, and annealing preserves acceptance across extreme finite scores.

* DONE Reject simulation time overflow consistently
Tick advancement is checked before callbacks; sleep requests reject overflowing
wake times before changing state. Both checks also apply in release builds.

* DONE Protect agent routing identity
AgentContext exposes its handle through =handle()= instead of a writable field.
=find_by_name_mut= returns mutable behavior and state, not a replaceable agent.
Command dispatch uses bounds-checked indexing.
