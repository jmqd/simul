#+title: Changelog

* DONE Fail license checks when collection or filtering fails
Preserve errors from cargo-license instead of reporting success for missing or
failed tooling. A license-filter error also fails the check.

* DONE Restore the nine-ball simulation example
Record the winning agent explicitly, give both normal-rules players unique names,
and queue the opening turn only for the chosen starter. Winning turns halt without
scheduling another turn. Label the APA and normal-rules result tables correctly.

* DONE Preserve short waits at large simulation timestamps
Subtract integer timestamps before converting waiting durations to floating point.
One-tick waits remain accurate above 2^53 and near the u64 time limit.

* DONE Refresh dependencies and tooling (September 2026)
Pin Rust 1.98.1 and update BLAKE3 to 1.8.7, Criterion to 0.8.2, log to 0.4.34,
and compatible Cargo lockfile dependencies, replacing yanked chacha20 0.10.1.
Keep the library MSRV at 1.85; tests and benchmarks require 1.86.
Frozen V1 seed vectors and a before/after replay comparison remain unchanged.
Update rust-overlay and nixpkgs; retain Intel macOS on the supported 26.05 branch.
Update Dylint to 6.0.4 with nightly-2026-05-28, native zlib, and published-driver
resolution so the Nix package does not reference a deleted build directory.
Verify native tests, Clippy, formatting, audit, docs, licenses, unused dependencies,
examples, an optimized benchmark, and the Nix build on Apple Silicon.
All four Nix platforms evaluate; Intel macOS and Linux builds were not exercised.
Dylint completes with non-fatal assertion-order and crate-wide-allow warnings.

* DONE Consolidate typed experiments and eager worker setup
Use one trial/replay protocol with bounded canonical serial and parallel runners.
Worker initialization is fallible and eager; explicit storage is allocated before
callbacks, and callback unwinding yields run-level errors without retries.
Remove the duplicate replicated runner, TrialKey alias, and simulation-coupled
search wrappers. Retain generic annealing and cross-entropy optimization.

* DONE Sample finite bounds without interval-width overflow
Opposite-sign extreme endpoints use a finite convex combination.
Representable-width intervals retain their existing deterministic samples.

* DONE Reject unrepresentable scalar statistics
Scalar reduction reports arithmetic overflow without changing accepted state.
Aggregation preserves that failure instead of returning non-finite statistics.

* DONE Share retained message contents without deep cloning
Message histories and delivery share strings and payloads with copy-on-write
mutation; completion timestamps remain independent. Construct messages with
=Message::new= or =Message::new_with_payload= instead of struct literals.

* DONE Use one replication result allocation
Workers fill disjoint output ranges directly; partial results are dropped on
failure. Worker-count tests cover single-CPU and unavailable-parallelism hosts.
The obsolete =WorkerChunkRecords= allocation-error variant was removed.

* DONE Preserve optimizer numerical boundaries
Circular proposals stay in =[0, 1)=, finite sampling and deviation smoothing
avoid overflow, and annealing preserves acceptance across extreme finite scores.

* DONE Reject simulation time overflow consistently
Tick advancement is checked before callbacks; sleep requests reject overflowing
wake times before changing state. Both checks also apply in release builds.

* DONE Protect agent routing identity
AgentContext exposes its handle through =handle()= instead of a writable field.
=find_by_name_mut= returns mutable behavior and state, not a replaceable agent.
Command dispatch uses bounds-checked indexing.
